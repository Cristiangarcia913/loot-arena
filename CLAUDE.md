# Loot Arena

## Resumen del proyecto

Loot Arena: Mini-RPG táctico 1v1 con render dual 2D/3D Three.js y Web3 Sepolia.

## Reglas

- Mantener arquitectura Vanilla ES Modules sin build step pesado.
- No romper rendimiento 3D.

## Regla Git Obligatoria

Al terminar cualquier tarea, verificar tests con `npm test`, hacer `git add .`, commit descriptivo y `git push origin main` automáticamente.

(Los tests del juego están en `web/`: ejecutar `npm test` desde esa carpeta.)
